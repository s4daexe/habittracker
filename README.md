# Habit Tracker 🍒
 
A simple, single-page habit tracker built with vanilla HTML, CSS, and JavaScript.
 
**Live demo:** https://s4daexe.github.io/habittracker/
 
## What it does
 
- Dynamically builds a calendar grid for the current month
- Click your habit's title to name it whatever you're tracking
- Click any day to mark it complete — progress saves automatically via `localStorage`, so it's still there next time you open it
- Live counter shows how many days you've completed out of the month
- Reset button to start fresh
## Built with
 
Vanilla JavaScript, HTML, and CSS — no frameworks or dependencies. Focused on DOM manipulation, date handling, and browser local storage for persistence.
 
## Why
 
Built as a small personal project to practice core JavaScript fundamentals — working directly with the DOM, `Date` objects, and `localStorage` — without relying on a framework.
